# Installation und Nutzung

Die sechs zusammengehörigen Repositories bilden den
[Compose-Stack](../../dateninfrastruktur-dev-stack/docs/operations.md).
Die Sodata-Anwendung ist nach dem expliziten Setup über das Gateway unter
`/` und `/datasets` verfügbar. Die
[Katalogfunktionen](database-catalog.md) und [Betriebshinweise](operations.md)
gelten für die installierte Version.
